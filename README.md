# Romantic Date App

Одностраничное романтическое веб-приложение без фреймворков.

## Запуск

Самый простой способ:

1. Распакуйте архив.
2. Откройте `index.html` в браузере.

Или через локальный сервер:

```bash
python -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000
```

## Где менять вопросы

Все фразы находятся в `config.js`.

Чтобы добавить новый экран, просто добавьте строку в массив `questions`:

```js
questions: [
  "Первый вопрос",
  "Второй вопрос",
  "Новый вопрос"
]
```

Приложение автоматически обновит количество экранов и индикатор прогресса.
